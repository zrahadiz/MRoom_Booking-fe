# 🏢 Meeting Room Booking System

A frontend web application for managing meeting room reservations.

Built with:

- 🎨 Frontend: React (TypeScript), Tailwind

---

# 🚀 Features

- 📋 View available rooms
- 📅 Check room availability (time slots)
- 📝 Create booking
- ❌ Cancel booking
- 📊 Pagination (rooms & bookings)
- ⏱️ Time-based conflict validation

---

# 🎨 Frontend Setup (React + TSX)

## 1. Install dependencies

```
npm install
```

---

## 2. Run frontend

```
npm run dev
```

Frontend akan jalan di:

```
http://localhost:5173
```

---

## 3. Setup API Base URL di env

Buat file `.env`:

```
VITE_BACKEND_URL=your_backend_url
```
